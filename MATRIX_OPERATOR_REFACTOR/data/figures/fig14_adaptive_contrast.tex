% fig14 (041a): end-to-end resident step time vs cluster density contrast
% (multiscale field, n = 1e6, H200, Float64, dense M2L, P = 4).  The uniform
% grid's cost blows up with contrast at every fixed depth (the fat-cell
% O(K^2) nearfield concentrates in the cluster; deeper ell trades it for
% route/refresh cost), while the adaptive octree (K_max = 64) stays flat:
% popmax = K_max by construction.  Per-depth uniform curves are thin gray;
% the orange envelope is the best gate-passing uniform depth per contrast.
% Data: fig14_adaptive_contrast/*.csv from fm041a_gpu_contrast.csv
% (H200 job 13184014; same-job anchors).  Series identity = color + mark +
% dash + legend, never color alone.
% Compile: pdflatex fig14_adaptive_contrast.tex

    legend pos=north west,
]
