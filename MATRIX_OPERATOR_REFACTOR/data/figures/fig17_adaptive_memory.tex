% fig17 (041a): device memory (bytes in use after construction, H200,
% n = 1e6, Float64, dense M2L) vs geometry parameter — uniform depth ell
% (orange, squares) against adaptive K_max (blue, circles; x = K plotted on
% the same log axis; K and ell are different knobs, the panels compare the
% MEMORY RANGE each machinery spans across its useful settings).  The
% uniform grid's capacity memory grows ~8x per depth level (dense node_at
% Sigma 8^ell table + per-cell capacity), while the adaptive tree's
% occupancy-sized capacity stays in a narrow band.  Missing points are
% depths that failed to construct (capacity/OOM) — recorded as fail rows in
% the CSV of record and quoted in the report.
% Data: fig17_adaptive_memory/*.csv from fm041a_gpu_widen.csv (H200 job
% 13184013).
