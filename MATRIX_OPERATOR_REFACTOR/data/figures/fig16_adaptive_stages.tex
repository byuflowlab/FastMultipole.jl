% fig16 (041a): per-stage lifecycle breakdown at n = 1e6 (H200, Float64,
% dense M2L, P = 4) — adaptive (K_max = 64) vs uniform depths, per case.
% Stacked bars: each stage launcher timed individually (CUDA event medians
% of 7, nearfield overlap and graph capture disabled so stages serialize);
% the stack therefore shows WHERE each machinery spends its time — the
% uniform grid's fat-cell direct(U) domination on wake/multiscale vs the
% adaptive tree's bounded near stage plus its new M2T/S2L cost.  The
% serialized stack overstates the shipped wall time (overlap + graph
% recover concurrency); the shipped whole-lifecycle time is the black tick
% on each bar.  Far-field family in blue shades, direct nearfield in
% orange, adaptive-only M2T/S2L in aqua shades, refresh in violet.
% Data: fig16_adaptive_stages/stages.csv from fm041a_gpu_stages.csv
% (H200 job 13184014).
