# Task 024 resident M2L benchmark data

`raw/` receives one common-schema CSV per isolated CPU/H200 matrix case.
`summary/` is generated by `scripts/summarize_024.jl` and contains:

- a raw-data provenance index;
- per-case M2L and recurring-step rankings;
- CPU and GPU crossover tables;
- construction-amortization break-even steps;
- memory feasibility; and
- unresolved/noisy-regime notes.

Cluster artifacts are intentionally absent until both displayed Slurm scripts
have been explicitly approved and run.  The fetch script validates complete
coverage, duplicate keys, finite eligible timings, explained infeasible rows,
correctness status, schema fields, and lifecycle counter invariants.
